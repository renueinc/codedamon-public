📘 はじめての方向け：サーバーURLの設定方法
  1. プロジェクトのルートフォルダ（start.sh があるフォルダ）を開く
  2. 同じフォルダにある .env.local をテキストエディタで開く
    ※ 見つからない場合は新規作成してください
  3. ファイルに次の1行を追加（URLは上の欄の値）
    CLOUD_BACKEND_URL=<サーバーURL>
  4. 保存してから bash start.sh を再実行してサーバーを再起動
💡 上の「.env 形式でコピー」ボタンで CLOUD_BACKEND_URL=... をクリップボードにコピーできます。「.env としてダウンロード」でファイルとして保存する場合は、ダウンロードした .env.zundamon を .env.local にリネームしてください。

❓ コードだもんの使い方

ずんだもんと一緒にコードを書こうなのだ！

🗣️ チャット
  • メッセージを入力して 送信 または Ctrl+Enter
  • ずんだもんが回答して音声で読み上げます
  • 🎤 ボタンでマイク入力も使えます
🛠️ 3つのモード
  • 確認 — ファイル編集前に承認を求めます（推奨）
  • プラン — 計画のみ立てて実行しません
  • 自動 — 確認なしで自動実行します
🔊 音声
  • 🔊 / 🔇 ボタンで音声のオン・オフを切り替えます
  • 無料プランは月30回まで音声を使えます
🌐 プレビュー
  • ヘッダの プレビュー ボタンで、任意の URL を画面内フレームで表示できます
  • ずんだもんに Web ページを作ってもらったとき、隣で確認するのに便利なのだ
🪟 分割
  • ヘッダの 分割 ボタンで、もう1つのチャットパネルを横に開きます (右は iframe)
  • 2つの作業を並行して進めたいときに使ってね
🔁 リレー
  • まず 分割 ボタンで2つのチャットパネルを開いてください — 分割モードが有効でないとリレーは使えません
  • 両方のパネルで 🔁 リレー を ON にすると、ずんだもん同士が自動で会話を続けます
  • 片方の応答が自動でもう片方に送信されます — 最大 6 ターンで自動停止します
  • リレーを止めるには 🔁 リレー を OFF にするか、新規チャット を押してください
👤 アカウント
  • 無料登録で月50リクエスト使えます
  • アバターをクリック → アカウント で使用状況を確認
